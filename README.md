# Template 2 — Landing Page editorial

Base editorial orientada ao contato por WhatsApp, com apresentação profissional, serviços, FAQ e localização.

## Fonte de dados

Edite `landing.data.json`. Nome, OAB, área, WhatsApp, localização, hero e serviços são consumidos diretamente pelo site. `src/config/template.config.js` mantém apenas os conteúdos complementares da composição.

## Executar

```bash
npm install
npm run dev
```

Antes de publicar:

```bash
npm run lint
npm run build
```

Este template contém somente a rota pública da Landing Page. Login, conta, catálogo e painel administrativo não fazem parte da base.
