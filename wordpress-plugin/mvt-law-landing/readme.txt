Landing page institucional da MVT Law empacotada como plugin WordPress.

== Instalação ==

1. No painel do WordPress, acesse Plugins > Adicionar plugin > Enviar plugin.
2. Selecione o arquivo ZIP deste plugin, instale e ative.
3. Crie ou edite uma página.
4. Em Modelo/Template, escolha "MVT Law — Landing Page".
5. Publique a página.

O template próprio é a opção recomendada porque evita duplicar o cabeçalho e o rodapé do tema ativo.

== Shortcode alternativo ==

Se o editor ou o tema não permitir selecionar templates, adicione este shortcode ao conteúdo de uma página:

[mvt_law_landing_page]

Nesse modo, o cabeçalho e o rodapé do tema continuam visíveis.
